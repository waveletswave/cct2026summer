# cct2026summer

Code and notes from the CCT PhD Computational Summer Fellowship (2026).

I'm a PhD student in Earth and Climate Sciences at Duke. Most of my work so far has been physically based hydrologic modeling and geospatial analysis in Python, and the fellowship is mainly about getting more comfortable with ecological and environmental data analysis in R. This repository holds the scripts and notebooks I write along the way.

Two projects shape what ends up here. The first is post-fire hydrologic response in the Southern Appalachians using DHSVM, where I'm working on LAI and NDVI and trying to compare the model against data more carefully. The second is a marsh modeling project in Brad Murray's group, looking at biomass, inundation depth, and vegetation patterns across sites.

The aim is a reproducible R workflow I can reuse, not a finished product. It will fill in as the fellowship goes.
